渋谷区「スクランブル・クロス」は8方向から地形で交差攻撃。1発のダメージは通常投擲の0.7倍。新宿区「都庁フィーバー」は10秒間、攻撃・防御・速度33％アップ。大田区「飛行機アタック」は大田区の地形が飛行機に乗って貫通突撃します。北海道「北海道はでっかいどう」の投射地形をさらに大型化。奥州市と下呂市の弾も、球体の代わりに実際の地形を使用します。3つの新固有技はSR以上、CPUも同じ技を使用します。

追加データはブラウザ保存・旧方式のセーブコード・大規模セーブコードに対応。旧コードには初期値を補います。時刻は端末時計を利用するため、時計改変やデータ巻き戻しへの完全な対策ではありません。実機iPadと公開先での動作は未検証です。

## 編成

## 公開

このフォルダの中身をGitHubリポジトリのルートへアップロードし、Settings → Pages → Deploy from a branch → main → / (root) を設定します。別のブランチ名なら実際の名前を選んでください。公開URLで index.html が入口になります。

GAS・対戦サーバー・CDNライブラリー・Git LFSは不要です。初回の約8.3MBと、必要になった町の形を配信元から取得します。file://による直開きには対応しません。
